## [Unreleased]

### Добавлено
- **CSV-импорт ретроспективных данных** (`CsvHistoryImportService` в `:data`, экран «Настройки» → «Импорт ретроспективных данных (CSV)» в `:app`): загрузка истории зарплаты за произвольные месяцы/годы по шаблону (оклад, классный чин, коэффициенты ЕДП/гостайна/особые условия/выслуга, премия, рабочие дни, отработанные дни). Каждая строка считается тем же Calculation Engine, что и остальное приложение (не переписывался); при разных коэффициентах в соседних месяцах выплата за вторую половину месяца корректно считается по коэффициентам ТОГО месяца, а не текущего. Предпросмотр с построчными ошибками и конфликтами, подтверждение стратегии (не перезаписывать/перезаписать) перед сохранением — существующие данные не затираются без явного согласия.

## [1.0.0] — Фаза 4 (финализация Android-проекта)

### Добавлено
- Android-приложение (Jetpack Compose, Material 3, MVVM, Clean Architecture).
- Calculation Engine (`:calculation`) — буквальная реализация формул из
  «Расчет ЗП (2026).xlsx»: оклад, классный чин, ЕДП, надбавки, выслуга, премия, дневная ставка,
  аванс/окончательная выплата, условный НДФЛ. `BigDecimal` везде, без `Double`/`Float`.
- История зарплаты с разделением «расчётное»/«фактическое» значение.
- Аналитика (зарплата по месяцам/годам, премии, надбавки, накопления).
- Финансовые цели с прогрессом и прогнозом даты достижения.
- Планы накопления: фиксированная сумма, процент от зарплаты, процент от премии, остаток после
  расходов; разные суммы по периодам года (`SavingsPeriod`).
- Прогноз (реактивный пересчёт при изменении зарплаты/плана/цели).
- What-If — сравнение сценариев без изменения сохранённых данных.
- Room-база данных (`SalaryHistory`, `FinancialGoal`, `SavingsPlan`, `SavingsPeriod`).
- DataStore для настроек приложения (тема, выбранный период, отображение).
- Импорт/экспорт: JSON-бэкап, CSV-история, безопасный импорт с подтверждением конфликтов.
- Адаптивный UI для смартфонов (Bottom Navigation) и планшетов (NavigationRail/Drawer,
  многоколоночные экраны, Master-Detail для истории).
- GitHub Actions workflow для сборки Debug APK и прогона unit-тестов.

### Известные ограничения
- `gradle-wrapper.jar` не включён в архив (бинарный файл, недоступен в офлайн-среде сборки —
  см. `docs/build-status.md`).
- Часть Compose-экранов напрямую использует типы `:data`/`:calculation` вместо отдельных
  UI-моделей — см. `docs/build-status.md`, раздел «Архитектурные отклонения».
- Исходный файл `Расчет ЗП (2026).xlsx` не включён в репозиторий (реальные персональные данные) —
  см. `docs/security-check.md`.
