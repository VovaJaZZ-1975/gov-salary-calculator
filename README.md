# Калькулятор зарплаты государственного гражданского служащего

Android-приложение для расчёта зарплаты государственного гражданского служащего, отслеживания
истории начислений, финансовых целей и накоплений — на основе реальной модели расчёта из
файла «Расчет ЗП (2026).xlsx» (полный разбор — `docs/excel-analysis.md`).

## Описание

Приложение воспроизводит формулы исходной Excel-модели (оклад, классный чин, ЕДП, надбавки,
выслуга, премия, дневная ставка, аванс/окончательная выплата, условный НДФЛ) в виде независимого
от UI расчётного модуля, добавляет историю расчётов, финансовые цели с прогнозом даты достижения,
гибкие планы накопления и сценарии «What-If» — полностью офлайн, без серверов и аккаунтов.

## Возможности

- **Расчёт зарплаты** — оклад, классный чин, ЕДП, выслуга, особые условия, гостайна, премия,
  рабочие/отработанные дни, дневная ставка, аванс и окончательная выплата — в реальном времени.
- **История** — ретроспектива по годам/месяцам, с явным разделением «расчётное» и «фактическое»
  значение (пользователь всегда видит источник цифры).
- **Аналитика** — зарплата по месяцам/годам, премии, надбавки, накопления на графиках.
- **Финансовый календарь** — аванс, окончательная выплата, премия, накопление, достижение цели по месяцам.
- **Финансовые цели** — несколько целей, прогресс, необходимое накопление в месяц, прогнозная дата.
- **Накопления** — фиксированная сумма, процент от зарплаты, процент от премии, остаток после
  расходов; разные суммы по периодам одного года (`SavingsPeriod`).
- **What-If** — сравнение текущего и альтернативного сценария (другой оклад/коэффициенты/премия)
  без изменения сохранённых данных.
- **Импорт/экспорт** — полный бэкап в JSON, история зарплаты в CSV, безопасный импорт с
  подтверждением конфликтов (ничего не перезаписывается без явного согласия).

## Архитектура

```
Compose UI  →  ViewModel  →  UseCase  →  Repository  →  Calculation Engine / Room
```

- **Jetpack Compose + Material 3** — весь UI, адаптивный (Window Size Classes) для смартфонов и планшетов.
- **MVVM + Clean Architecture**, три Gradle-модуля:
  - `:calculation` — чистый Kotlin/JVM модуль, независимый от Android. Формулы расчёта, `BigDecimal`
    везде (никакого `Double`/`Float` для денег), версионируемая конфигурация коэффициентов, What-If.
  - `:data` — Room (история, цели, планы накопления), DataStore (настройки), Repository, доменные
    сервисы (`SavingsCalculator`, `ForecastService`, `WhatIfService`), импорт/экспорт.
  - `:app` — Compose UI, ViewModel, UseCase-слой, навигация, тема.
- Полный разбор исходной Excel-модели, архитектурные решения и открытые вопросы — в `docs/`.

> Известное отклонение от идеальной слоистой архитектуры: часть экранов `:app` напрямую использует
> типы модулей `:data`/`:calculation` (Room-сущности и типы Calculation Engine) вместо отдельных
> UI-моделей. Подробности и обоснование — `docs/build-status.md`.

## Поддерживаемые устройства

- Смартфоны и планшеты, portrait и landscape, split-screen и изменение размера окна
  (Window Size Classes: Compact/Medium/Expanded).
- Смартфон: Bottom Navigation. Планшет: NavigationRail/Drawer, адаптивные многоколоночные экраны
  (Dashboard, История — Master-Detail).

## Сборка

```bash
git clone <url-вашего-репозитория>
cd gov-salary-calculator
./gradlew assembleDebug
```

Для Windows:

```bat
gradlew.bat assembleDebug
```

Запуск тестов:

```bash
./gradlew test
```

### Требования

- Android Studio (Koala или новее) либо JDK 17+ и Gradle отдельно.
- Android SDK: `compileSdk 34`, `minSdk 26`, `targetSdk 34`.
- Интернет при первом Gradle Sync (для загрузки зависимостей и `gradle-wrapper.jar`, который не
  включён в этот архив — см. `docs/build-status.md`).

## Данные

Исходный файл `Расчет ЗП (2026).xlsx` содержит реальные персональные данные (ФИО и историю
фактических выплат в примечаниях к ячейкам) и **намеренно не включён** в этот репозиторий —
см. `.gitignore` и `docs/security-check.md`. Обезличенный набор коэффициентов для разработки и
тестов — `sample-data/` и `CalculationConfiguration.excel2026Baseline()` в модуле `:calculation`.
