## Test Case 001 — Базовая сумма начисления (месячная база)

**Вход:**
- Должностной оклад = 24 296 (`W14`)
- Оклад за классный чин = 13 853 (`W15`)

- Коэффициент «за особые условия» = 1.2 (`X18`)
- Коэффициент «за выслугу лет» = 0.1 (`X19`)
- Премия (в этом блоке) = 0

**Промежуточные значения:**
- ЕДП = 21 866.4 (`W16`)
- За гостайну = 2 429.6 (`W17`)
- За особые условия = 29 155.2 (`W18`)
- За выслугу лет = 2 429.6 (`W19`)

**Ожидаемый результат:**
- Итого (после множителя 0.87) = **81 805.926** (`W21`)

**Источник:** `Расчет ЗП (2026).xlsx`, ячейки `W14:W21`, `X16:X19`.

## Test Case 006 — Итого за февраль (с премией)

## Test Case 007 — Итого за январь (граничный месяц, нет данных за декабрь 2025)

**Вход:**
- Выплата 4 января (2-я пол. декабря 2025) = не рассчитана, ячейка `AA29` пуста
- Выплата 19 января = 21 814.92 (`AA30`)
- Премия за январь = 0 (`AA31`)

**Ожидаемый результат:**
- Итого = 0 + 21 814.92 + 0 = **21 814.92** (`AA32`)

**Примечание:** этот итог заведомо неполный — отсутствует выплата за 2-ю половину декабря 2025 (см. `open-questions.md`, пункт 3). Тест фиксирует фактическое поведение файла, а не «правильное» с точки зрения полноты годового дохода.

**Источник:** `AA32`, `AA29:AA31`.

## Test Case 008 — Итого за август (месяц с максимальной премией)

**Вход:**
- Дневная ставка июля = MROUND(81 805.926 / 23, 0.01) = 3 556.78 (`AG24`, дни `AG25`=23)
- Рабочих дней после 15 июля = 12 (`AG27` = 23−11)
- Выплата 4 августа = MROUND(3 556.78 × 12, 0.01) = 42 681.36 (`AH29`)
- Дневная ставка августа = MROUND(81 805.926 / 21, 0.01) = 3 895.52 (`AH24`, дни `AH25`=21)
- Рабочих дней до 15 августа = 10 (`AH26`)
- Выплата 19 августа = MROUND(3 895.52 × 10, 0.01) = 38 955.20 (`AH30`)
- Премия за август = 44 007 (`AH31`)

**Ожидаемый результат:**
- Итого = 42 681.36 + 38 955.20 + 44 007 = **125 643.56** (`AH32`)

**Источник:** `AH32`, `AH29:AH31`, `AG24:AG27`, `AH24:AH26`.
