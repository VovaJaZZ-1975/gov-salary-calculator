# Обезличенный пример данных

Исходный файл `Расчет ЗП (2026).xlsx` содержит реальные персональные данные (ФИО автора и
историю фактических выплат за 2021-2025 гг. в примечаниях к ячейкам — см.
`docs/excel-analysis.md`, раздел 9) и **не включён** в этот репозиторий (см. `.gitignore` и
`docs/security-check.md`).

Для разработки, тестов и демонстрации используется обезличенный набор коэффициентов —
он же воспроизводит действующий расчётный блок исходного файла (`P13:X21`), но без каких-либо
персональных данных (имён, дат, истории выплат конкретного человека):

```kotlin
// calculation/src/main/kotlin/ru/govsalary/calculation/config/CalculationConfiguration.kt
CalculationConfiguration.excel2026Baseline()
```

а также golden-данные в `docs/test-cases.md` и `calculation/src/test/.../ExcelGoldenTest.kt`.

Если нужен файл именно в формате `.xlsx` для ручного тестирования импорта, создайте его
самостоятельно на основе структуры, описанной в `docs/excel-analysis.md` — это не входит в
поставку репозитория намеренно.
